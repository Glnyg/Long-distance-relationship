# 代码生成总规则

## 这份文档是什么

这份文档是本项目的工程规范体系总入口。以后无论是 AI 写代码，还是人工写代码，都必须先看项目文档，再写代码。

初学者可以这样理解：

- 设计文档说明“应该做什么”。
- 功能文档说明“用户怎么用、系统怎么处理”。
- 工程规范说明“代码应该怎么写、怎么检查、怎么排查问题”。
- 代码只是实现结果，不能反过来决定产品规则。

## 最高规则

本项目继续坚持：文档是唯一事实源。

后续任何代码生成必须先确认：

- 是否已经阅读 `docs/00-AI-Project-Handbook.md`。
- 是否已经阅读对应设计文档和功能文档。
- 是否需要更新权限隐私文档、ADR、变更记录。
- 是否涉及情侣聊天、定位轨迹、用机状态、AI 分析等敏感数据。
- 是否已经设计日志、Trace、Metric、Alert。

如果文档和代码冲突，以文档为准。正确做法是先更新文档，再更新代码。

## 语言规则

本项目主要用中文维护。文档、变更记录、功能说明、错误解释默认使用中文。

允许保留英文的地方：

- 代码标识符。
- 包名。
- API 路径。
- 第三方库名。
- 命令。
- 官方术语，例如 `OpenTelemetry`、`Trace`、`Metric`、`Alert`。

文档里出现英文术语时，应尽量给出中文解释。

## 新手注释规则

本项目要求代码和配置中带有必要注释，方便初学者理解项目。

需要写注释的地方：

- 业务规则复杂、容易误改的地方。
- 授权、隐私、审计、AI、日志、Trace、Metric、Alert 相关代码。
- PowerShell 门禁脚本中的关键检查逻辑。
- GitHub Actions 中的构建、测试、部署步骤。
- Kubernetes YAML 中的 Secret、持久卷、健康检查、资源限制、端口、服务发现。

注释写法：

- 优先用中文。
- 解释“为什么这样做”，不要只重复“这行代码做了什么”。
- 隐私相关注释必须说明不能记录哪些敏感数据。
- 配置文件注释必须说明这个组件的用途和生产环境注意事项。
- 代码改动后要同步更新注释，过期注释比没有注释更危险。

不推荐：

- 每一行都加注释。
- 写“设置变量”“调用方法”这类没有帮助的注释。
- 在注释里写真实密码、token、手机号、位置、聊天内容等隐私数据。

## 隐私优先规则

本项目处理情侣聊天、位置、设备状态和 AI 分析结果，这些都是高敏感数据。

代码生成时默认禁止：

- 在日志里打印聊天原文。
- 在日志里打印完整经纬度。
- 在日志里打印 Wi-Fi 名称。
- 在日志里打印手机号、验证码、token。
- 保存 prompt 原文。
- 保存模型输入快照。
- 未经双方同意进行 AI 分析。
- 后台偷偷分析关系状态。

允许保存和记录的是排障需要的元数据，例如错误码、耗时、数据类型、授权版本、模型 ID、token 用量、脱敏后的用户标识。

## 测试优先规则

任何功能变更都必须考虑测试。

最小要求：

- 业务规则有单元测试。
- 敏感权限和授权逻辑有反向测试，例如“未授权必须失败”。
- AI 功能必须测试输入不落库、审计无隐私原文、失败可解释。
- 服务端接口必须测试解绑、撤回授权、越权访问。
- Android 功能必须覆盖拒绝权限、权限被系统收回、后台受限。

## 可观测性优先规则

可观测性是指系统出问题时，工程师能知道“哪里出了问题、影响多大、为什么发生”。

每个新功能都必须说明：

- 需要记录哪些结构化日志。
- 需要哪些 Trace span。
- 需要哪些 Metric 指标。
- 什么情况需要 Alert 预警。
- 哪些字段必须脱敏。

不允许为了排障方便而记录隐私原文。

## 代码生成前检查清单

写代码前必须确认：

- 对应中文功能文档已经存在。
- 设计文档和功能文档没有冲突。
- 涉及敏感数据时，授权规则已经明确。
- 涉及 AI 时，只能通过 `AiPrivacyGateway`。
- 涉及服务端时，必须使用结构化日志和 OpenTelemetry。
- 涉及 Android 时，必须有权限拒绝后的降级方案。
- 涉及接口时，必须有稳定错误码和中文错误解释。
- 关键代码、脚本和配置已经规划新手可读注释。

## 代码生成后检查清单

提交前必须运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Assert-ProjectGate.ps1
```

如果只想快速检查文档：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Assert-DocsGate.ps1
```

如果检查失败，不要绕过门禁。应修正文档、代码或测试。
