# 锁屏答题

## 目标

用户主动开启后，可以触发一次系统锁屏，并在 App 内通过答题完成情侣互动。

## 能力边界

首版使用设备管理员能力触发系统锁屏。系统解锁仍由 Android 系统负责，App 不能绕过或替代系统锁屏密码。

答题通过后，App 只能解除 App 内限制、提醒或任务状态，不能直接破解系统锁屏。

## 用户流程

1. 用户开启锁屏答题功能。
2. App 明确说明设备管理员权限用途和关闭方式。
3. 用户授权设备管理员。
4. 用户或对方触发锁屏答题。
5. 手机系统锁屏。
6. 用户按系统方式解锁手机。
7. 回到 App 后回答问题。
8. 答对后任务完成。

## 禁止实现

- 不使用无障碍服务强制覆盖屏幕。
- 不使用悬浮窗做假锁屏。
- 不阻止用户卸载。
- 不绕过系统密码。

## 审核注意

必须清楚说明设备管理员权限用途，否则上架风险高。
