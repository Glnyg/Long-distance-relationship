# 聊天、语音和视频

## 目标

绑定情侣之间可以进行一对一聊天、语音通话和视频通话。系统不提供群聊、大厅、陌生人聊天。

## 聊天范围

- 文本。
- 图片。
- 语音消息。
- 已读状态。
- 撤回。

## 音视频范围

- 一对一语音通话。
- 一对一视频通话。
- 通话邀请、接听、拒绝、结束。

## 技术方案

- 文本聊天使用服务端消息服务和 SignalR。
- 图片和语音消息使用对象存储保存文件，数据库保存元数据。
- 音视频使用第三方 RTC。
- 服务端 `RtcGatewayService` 只负责 token、权限、回调和审计。

## 隐私

- 首版聊天采用服务端加密存储，不做端到端加密。
- 未经双方 AI 授权，聊天内容不得进入 AI 分析。
- 日志不得打印聊天原文。

## 失败与降级

- WebSocket 断开：回退轮询或下次同步。
- RTC token 失败：不能进入通话。
- 麦克风或摄像头拒绝：只允许对应能力降级。

## 审核注意

必须明确说明麦克风和摄像头只用于情侣语音/视频。
