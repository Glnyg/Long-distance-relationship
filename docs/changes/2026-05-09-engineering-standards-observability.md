# 2026-05-09 工程规范体系与全链路可观测性

## 变更内容

- 新增工程规范体系，替代泛称 `tools`。
- 新增代码生成、服务端、Android、AI 隐私、可观测性与预警规范。
- 新增 AI 代码生成任务模板、接口文档模板、可观测性检查清单。
- 新增项目总门禁、隐私日志门禁、可观测性门禁规划。
- 新增 `AIAPP.Observability` 共享类库规划。

## 原因

项目会持续新增敏感功能和 AI 能力，需要用统一规范约束后续代码生成，避免文档缺失、日志泄露隐私、系统不可排查、异常无法预警。

## 影响

- 后续新增功能必须同步工程规范要求。
- 后续 ASP.NET Core 服务必须接入 OpenTelemetry。
- 后续 Android 客户端必须按 `core:observability` 方向设计客户端观测事件。
- 隐私原文不得进入日志、Trace、Metric。
