# AIAPP

Initial application workspace.

## Directory layout

- `src/` - application source code
- `tests/` - automated tests
- `docs/` - project documentation
- `scripts/` - local development and maintenance scripts
- `config/` - configuration templates and defaults
- `data/raw/` - local raw data, ignored by Git except placeholders
- `data/processed/` - local processed data, ignored by Git except placeholders
